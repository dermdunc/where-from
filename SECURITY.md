# Security

**What counts here.** A receipt that reports `fresh` when what it cites has changed, or any way to make `check` pass over stale or missing sources. Also anything that lets source content or a snapshot make the tool read, write or execute something it shouldn't. The README's "Mechanics worth knowing" says what is deliberately trusted (a snapshot you're handed is trusted input).

**How to report.** Use GitHub's private vulnerability reporting on this repository (the Security tab, then "Report a vulnerability"). Please don't open a public issue for these. This is a one-maintainer exhibit, so there is no response-time promise, but these reports are the ones read first.
